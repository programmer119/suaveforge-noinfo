# SuaveForge No-Contact Homepage

thoughtbot의 결과 중심 사례 구조와 Work & Co의 대형 제품 화면·편집 리듬을 참고해, SuaveForge의 실제 구현 자료와 5인 책임 구조를 중심으로 재구성한 정적 홈페이지입니다.

## 로컬 실행

압축을 푼 폴더에서 실행합니다.

```powershell
py -m http.server 8080
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8080
```

## 핵심 변경

- 모바일 첫 화면에 실제 구현 화면을 바로 노출
- 콘텐츠를 가리던 모바일 고정 문의 버튼 제거
- 5명, 같은 담당자의 지속 관리, 16개 작업, 자동화 검증과 3개월 품질보증을 첫 화면 아래에서 요약
- 대표 사례를 기능 목록이 아닌 고객 업무 변화와 검증 가능한 결과 중심으로 재구성
- `Windows 설치형 제품`, `기능 검증 데모`, `UI/UX 데모`처럼 프로젝트 성격을 카드에 명확히 표시
- 대표 사례 3개 우선 노출 후 2개를 선택적으로 펼치는 구조로 모바일 길이 축소
- 고객 상태별 진입점 추가: 아이디어, 기획서, 기존 프로그램, 운영 중 시스템
- 5명 전원의 역할과 관련 구현 영역 연결
- 요구사항 정리부터 자동화 검증, 납품·인계와 3개월 품질보증까지 한 구간에서 안내
- 전체 프로젝트 데이터를 `data/projects.js`로 분리
- 공개 연락처와 문의 폼을 포함하지 않는 별도 배포본

## 공개 정보 원칙

이 저장소는 연락처가 표시되지 않는 외부 포트폴리오용 배포본입니다. 연락처와 문의 전송 설정을 추가하지 않습니다.

## 프로젝트 수정

프로젝트 제목, 구분, 기술 스택, 설명, 구현 범위, 이미지와 공개 URL은 아래 파일에서 수정합니다.

```text
data/projects.js
```

이미지는 다음 경로 아래에 저장합니다.

```text
assets/portfolio/
```

## 배포

GitHub Pages 저장소 루트에 파일 전체를 올리면 됩니다.

- `CNAME`: `noinfo.suaveforge.com`
- `.nojekyll`: 유지
- 정적 자산은 모두 상대경로 사용

## 브라우저·홈 화면 아이콘

`assets.zip`에 포함된 SuaveForge 정식 로고를 사용합니다.

- `favicon.ico`: 구형 브라우저 및 `/favicon.ico` 기본 요청
- `assets/favicon/favicon.svg`: 최신 브라우저 탭 아이콘
- `assets/favicon/favicon-16x16.png`, `favicon-32x32.png`: PNG 대체 아이콘
- `assets/favicon/apple-touch-icon.png`: iPhone/iPad 홈 화면
- `assets/favicon/android-chrome-192x192.png`, `android-chrome-512x512.png`: Android/PWA
- `site.webmanifest`: 설치형 웹 앱 메타데이터

기존 아이콘이 캐시에 남으면 강력 새로고침하거나 브라우저의 해당 사이트 캐시를 지워야 합니다.


## v6.3 문구·경력 로고 정리

- 경력 회사 로고는 임의 제작 SVG를 제거하고 최초 홈페이지에서 사용하던 회사 아이콘 소스로 복원했습니다.
- 홈페이지의 제작 과정 설명, 방어적인 표현, 임시 문구와 추상적인 표현을 제거했습니다.
- 대표 문구와 프로젝트 설명, 납품·유지관리 안내를 자연스러운 상업용 문장으로 교체했습니다.

## v6.4 문구·가독성 정리

- 외부 포트폴리오 안내와 링크 제거
- 페이지 전체 문구를 자연스러운 상업용 한국어로 교체
- 본문·라벨·버튼 최소 글자 크기와 명암 대비 강화
- 실제 프로그램 화면이 잘리지 않도록 대표 이미지 표시 방식 조정
## v6.5 가시성 최종 조정

- 고객에게 보이는 보조 텍스트의 최소 크기를 데스크톱 13px, 모바일 14px로 상향했습니다.
- 이미지 위 캡션은 불투명도 96%의 어두운 배경과 텍스트 그림자를 적용했습니다.
- 태그와 메타정보는 글자를 줄이는 대신 내부 여백을 늘렸습니다.
- 모바일 입력 요소는 16px 이상을 유지해 브라우저 자동 확대를 방지합니다.

## v6.6 Experience 정리

- 경력 회사마다 반복되던 `재직 경력` 문구를 없애고 `구성원이 근무한 회사`로 한 번만 묶었습니다.
- 회사 로고는 한 번 내려받아 `assets/company-logos`에 저장한 실제 이미지 파일을 직접 제공합니다.
- 실행 중 Google favicon이나 회사 홈페이지에 이미지 요청을 보내지 않습니다.
- 외부 프로젝트와 회사 경력을 시각적으로 분리했습니다.
- 사람별 담당 회사와 재직 기간은 확인된 실제 정보가 준비될 때까지 추가하지 않았습니다.
- `그 밖에 해온 일`은 `산업별 구축 경험`으로 바꾸고 별도 영역으로 정리했습니다.

## v6.7 핵심 변경

- 핵심 전문 분야를 업무 자동화와 소프트웨어 재구축으로 명확히 재정의
- 소스가 없는 기존 프로그램도 동작·파일·통신·데이터 구조를 분석해 새 코드로 재개발한다는 설명 추가
- 범용 광고 문구를 사실 중심 문장으로 전면 수정
- 기존 장기 무료수정 표현 삭제
- 자체 자동화 테스트와 3개월 품질보증을 하나의 논리로 재구성: 검증을 통과한 결과물만 납품하고, 만약 납품 범위의 오류나 업데이트 문제가 발견되면 추가 비용 없이 정비
- 문의 유형에 `소스 없는 프로그램 재구축` 추가


## v6.8 핵심 변경

- 품질보증 문구를 `자동화 테스트 → 검증 통과 → 만약의 경우 3개월 보증` 순서로 재작성
- `무료 수정`처럼 보이던 빨간 판촉형 카드를 제거하고, 검증 근거가 먼저 읽히는 편집형 품질보증 영역으로 재구성
- `만약`을 별도 조건 표기로 두어 오류를 일반적인 다음 단계가 아닌 예외 상황으로 표현
- `3개월간`만 제한적으로 강조해 보증 기간은 선명하게 보이되 할인 문구처럼 보이지 않도록 조정
